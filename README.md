# Quiet Home add-ons

Home Assistant add-ons for the Quiet Home TV launcher, a personal Samsung TV
home screen.

## Quiet Home Hub

Serves photos, living-room controls, weather and family notes to the TV and adds
a **Quiet Home** page to the Home Assistant sidebar for managing photos and notes.
See [the add-on docs](quiet_home_hub/DOCS.md).

To install: in Home Assistant open **Settings → Add-ons → Add-on store → ⋮ →
Repositories**, add `https://github.com/pixelhop-glitch/quiet-home-addons`, then
install **Quiet Home Hub**.

This repository is published from the private Quiet Home project; changes are
made there and copied here.
